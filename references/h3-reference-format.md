# H3 全参考模式格式

适用 Ref2VA：图片、视频或音频分别为人物、环境、动作、关键帧、镜头结构或声音提供参考。先分配素材职责，再写表演；素材多不意味着所有内容都必须继承。共同的镜头、英文正文、对白和声音格式见 [基础格式](h3-base-format.md)。

核验日期：2026-10-10。来源：[官方 SKILL.md](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/SKILL.md)、[官方 ref-en.txt](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt)，重点为第 1–6 节。以下是原创整理的协议要点，不构成对实际生成或参考保真结果的证明。

## 1. 六个字段按固定顺序输出

```text
subject_definitions:
...

summary:
...

retention_analysis:
...

detailed_description:
...

overall_soundscape:
...

non_diegetic_music:
...
```

这六个字段组成完整可复制正文，即使用户只要提示词，也保留其中的 `retention_analysis`；它是参考处理的输出字段，不是额外的内部思考。分析仅写素材职责、保留方式和出现位置，不输出冗长推理。不要混入基础模式的 `integrated_multimodal_description`，也不要在六字段前套用 I2VA 等模式的首行。

六部分正文用英文。只有 `<d>` 中的台词／歌词和画面内实际出现的文字保留原语言；用户需要中文理解说明时，可在正文外另给精简说明。

## 2. 标签代表用途，不只是文件类型

| 标签 | 代表什么 | 易错点 |
| --- | --- | --- |
| `<Subject N>` | 从素材抽取并在成片使用的可见内容，包括角色、环境、服饰、道具、动作、表情或风格 | 不限于人物，也不等于原文件；同一内容可来自多个素材 |
| `<Picture N>` | 图片本身作为具体帧、构图或分镜锚点 | 只供人物长相时，不自动把整张图变成首帧 |
| `<Video N>` | 整条视频的编辑源、续接源或时间／镜头结构 | 单独借用其中动作、人物或场景时，相关可见内容仍归 Subject |
| `<Audio N>` | 实际启用的独立音频或参考视频音轨 | 视频文件带声音不意味着它已被选作音频参考 |

`subject_definitions` 为后续需要单独追踪的内容逐项写一行，说明标签、职责、关键保留特征；必要时注明源素材。只用来说明来源、不单独承担目标帧或结构作用的 Picture／Video，可在 Subject 定义中引用，无须再为它建独立条目或伪造保留项。

例如，一个 Subject 的外貌来自图片、走路动作来自视频时，可在同一定义里交代两者分工。角色是同一个，不能因两份素材生成两个人。反过来，一张图也可以同时提供角色和环境两个 Subject。

标签在定义、摘要、保留分析、镜头与声音字段中始终同义。`<Video N>` 与 `<Audio N>` 各自编号；数字相同不证明同源，数字不同也不排斥同源。必要时用一句话指出共享来源。所有标识必须能追溯到实际提供的素材，不创建不存在的图、视频或声轨。

## 3. summary 描述实际任务关系

用一个简短英文段落，开头以方括号标记实际任务类型；多个类型用 ` + ` 连接且不重复：

| 类型 | 判定条件 |
| --- | --- |
| `keyframe completion` | 图片承担目标首帧、尾帧、关键帧或其他明确帧锚点 |
| `reference generation` | 为人物、环境、风格、动作、运镜或分镜提供生成指导 |
| `video editing` | 直接修改原视频；编辑图片或连接静帧不属于此项 |
| `video continuation` | 从原视频接续、延伸或恢复内容 |
| `audio reuse` | 直接复用全部或部分音频信号 |
| `audio reference` | 不复制信号，只借用音色、节律、台词内容或声音质地等 |

摘要只使用已定义的标签，交代目标片段和主要素材分工。有视频参考但只是借镜头节奏时，不应写成视频编辑；有音频文件但不用其声音时，不自动追加音频类型。

视频编辑任务在类型前缀后使用官方指定开句，按实际源视频替换编号：

```text
The target video is an edited version of <Video 1>.
```

保留原视频音轨属于音频复用；续拍时重新生成类似环境声而不复制原波形，属于音频参考。二者不能只因“听起来连续”就混为一类。

## 4. retention_analysis：按已定义职责判断

每个单独追踪的标签占一行，沿用定义；可见内容说明出现在哪些镜头，帧锚点说明首帧／关键帧／尾帧，视频结构说明借用的范围。关系标记保持以下英文值，不自行翻译成新枚举。

| 可见参考标记 | 使用条件 |
| --- | --- |
| `fully_preserved` | 该标签已定义的参考职责完整保留 |
| `partially_preserved` | 仍使用该内容，但部分已定义特征改变或未保留 |
| `attribute_transfer` | 特征转移到另一个可辨别的目标主体 |
| `weak_reference` | 只保留风格、类别、构图或氛围等宽泛相似 |

```text
<Subject 1> (appears in [Shot 1]): fully_preserved - The referenced clothing and identity remain consistent.
```

保真范围由定义决定。人物参考只负责身份和衣装时，新增动作或改变场景不自动变成“部分保留”；不要把角色图中的静止表情、站姿和背景无条件锁死。相反，Picture 已被定义为完整尾帧时，不能只保留脸却声称整张尾帧完全保留。

| 音频参考标记 | 使用条件 |
| --- | --- |
| `fully_copy` | 完整原音频直接成为目标视频的完整最终音轨 |
| `partially_copy` | 只复制部分时间或声层，或复制后增删／替换声音 |
| `reference` | 不直接复制信号，只借音色、节奏、内容或质地 |
| `weak_reference` | 仅有宽泛类别或氛围相似 |

“保留原声音，再加一次呼吸／新对白／配乐”不是 `fully_copy`。即使把整段来源配乐用满，只要它不是最终全部声音，也不能用此标记声称完整音轨复制。`retention_analysis` 中不写 `(Sx)` 发声编号。

这些标记表达目标设计中的保留计划。只有实际检查生成视频后，才能报告是否实现，不能将字段名当作验证结论。

## 5. detailed_description：将参考落实到表演位置

与基础模式不同，Ref2VA 先用一两句英文建立全片风格，再开始 `[Shot 1]`。首镜无时间戳；后续切镜用 `[Shot N] At MM:SS.mmm, ...`。镜头编号对应真正切镜，表演中的接收、犹豫、回应可在同一镜头连续发生。

重要 Subject 首次清楚出现时，写当前可见的特征、位置和动作，随后沿用标签。每镜包括当前构图、环境与光、行动及状态变化、必要运镜和声音，并在参考真正生效的位置引用对应标签。不要只写“按照图片演”“参考视频动作”，也不要只列剧情梗概。

- 帧锚点写明镜头从哪张图开始、关键帧对应哪张图、在哪里落到尾帧。
- 视频编辑／续接在原状态或结构实际适用处引用 Video；不能拿来源视频替代对目标行动的描述。
- Audio 在实际启用的镜头或声音阶段出现，并说明是复用信号还是参考某种特征。
- 面部变化服从角色与当前事件；角色身份参考本身不要求继承原图的笑容、惊恐或僵直姿态。

官方为生成任务的 `detailed_description` 建议通常 350–500 个英文词，单镜头也不自动缩短；视频编辑可按源视频复杂度调整，密集对白优先完整表达声音时间线。该建议不是必须增加动作的配额。用户明确要求字数更少时优先满足用户限制，并保留关键因果、引用、台词和六字段；不要为凑词增加情节、无关表情或重复说明。

## 6. 发声编号、音色参考与原音复用

`<Subject N>` 标识可见参考内容，`(Sx)` 标识目标视频中的实际发声者；编号独立。按实际发声先后统一分配 `(Sx)`，人物在画外发声仍沿用同一个编号。音频定义若绑定该说话者，沿用其既定编号，不另起一套。

```text
<Audio 1> is the voice-timbre reference for <Subject 2> (S1).
```

实际发声时同时写 Subject 和 Sx，语气与动作放在 `<d>` 外，语言标签与台词放在里面。未定义成可见 Subject 的旁白声源用稳定声音描述加 Sx。声源在镜头间持续时沿用编号，不能按镜头重新编号。

直接复用的配乐／整条音轨中，如果某句歌词只是动作同步的提示，没有独立人物或旁白声源实际发出它，就使用 Audio 作为来源，不另造一个 Sx，也不能让画面人物自动开口跟唱。若确实有角色唱、说或旁白发声，则分配其 Sx。

**只参考音色**：生成目标台词时借用声音特征，不把参考录音里的词自动带进剧情。**复用原音或明确要求重演其内容**：保留来源词句和原语言；听不清的片段写 `[unclear]`，不能凭猜测补全。

官方对参考音频转录要求使用基本标点、清理装饰性符号，并以句号／问号／感叹号结束完整句子。这适用于整理参考音频内容，不能扩张为“重写用户台词”。用户已逐字锁定的台词、标点与特殊符号优先保持；说明格式差异即可，不暗中规范化、翻译或润色。画面可见文字也保留原文。

## 7. 声音字段与最终核对

`overall_soundscape` 概括环境和物理声，`non_diegetic_music` 写观众配乐。引用音频的复用／参考关系只写在实际对应的声层字段；同一音频同时提供环境和配乐时，分别说明相关声层。完整台词与歌词只在 `detailed_description` 的 `<d>` 内出现，不在两处声音字段重复。

- 六字段齐全有序，正文英文，标签无悬空、跨字段不变义。
- 独立帧锚点与角色／动作参考分开；参考影片有声音不自动继承声轨。
- 保留标记与素材职责一致，整轨复制与增删声音没有矛盾。
- 音色参考未偷带原词，歌词同步未让无声角色成为说话者，Sx 编号按实际发声统一。
- 参考生效位置具体可见，重要反应有观察时间，尾帧和未完成动作按用户要求停住。
